Maak hier een account aan op GitHub.com . Kies een goede gebruikersnaam, want die verschijnt bovenin je URL. Onfatsoenlijke namen: Deze sites worden niet nagekeken. Verifieer je emailadres, daar ontvang je een code. Vul de code in op de site en ga verder met ‘For free’. Repository aanmaken Nu heb je een plek nodig om bestanden handig op te bergen. Een website bestaat uit behoorlijk wat bestanden. Elk document, elke afbeelding, elke video is een bestand. Elk bestand moet opgeslagen worden, dus bewaard worden. Om bestanden op te slaan, maak je een soort kast aan, bewaarplaats, of hoe je het wilt noemen. Op GitHub heet dat repository. Je gaat al je bestanden voor dezelfde website in 1 repository zetten, in 1 kast. Maar….gelukkig heeft een kast planken om de spullen te organiseren. Want alles door elkaar zetten is niet handig. Maar dat komt later. Eerst de repository maken: Maak een nieuwe repository aan, via de + rechtsboven, of via een andere knop Geef deze de naam: username.github.io , waarbij de username jouw gebruikersnaam is. Als de naam is goedgekeurd, vink je aan ‘Public’ en zorg je dat er een Readme file gemaakt wordt. Dit is good practice….. Klik dan op Create Repository Bekijk je profiel. Via dat dropdownmenu kun je je repositories vinden en openen. Foute naam repository De naam van de repository moet exact gelijk zijn aan je username, gevolgd door .github.io. Dus niet: .github.com, .github.nl, .github-io. Dat werkt allemaal niet. Je moet zorgvuldig zijn. Heb je je repository een verkeerde naam gegeven, open hem dan, ga naar settings en verander de naam van je repository en klik op Rename. Sla je inloggegevens op, of maak er een foto van, zodat je de volgende keer makkelijk en snel in kunt loggen. Werken met de editor Veel mensen denken: “Ha, ik ga lekker makkelijk doen, klik, klik klik en ik neem een kant & klare template, dat ziet er direct mooi uit.” Daar mag je later voor kiezen. Want een template, zoals bootstrap, of een template van GitHub zelf is inderdaad prima, maar….daar heb je wat kennis voor nodig van HTML en CSS. Dus die gaan we eerst opbouwen….. Zorg dat je ingelogd bent Open je repository Homepage In je repository ga je naar Add file, en klik je op Create new file. De Homepage van een website heeft altijd dezelfde naam: index.html Tik deze naam in. Scroll naar beneden: Daar moet je de veranderingen opslaan. Dit heet in Github: Commit. Dit betekent ‘uitvoeren’. In dit geval heb je een nieuw file, oftewel nieuw bestand gemaakt. Tik evt. een beschrijving in en klik dan op Commit new file. In je repository is dit bestand nu verschenen. Werken met bestanden: Webeditor openen Zorg dat je ingelogd bent. Klik op de naam van het bestand index.html en dit scherm opent: Klik op ‘Open in github.dev’ Klik bij het potloodje en klik op ‘Open in github.dev’ Setting up the webeditor…. ….en je krijgt de volgende pagina. Links het menu en overzicht van de bestanden. Rechts de editor, waar je code intikt. Menu van de webeditor Scroll over de menu-onderdelen links Een paar onderdelen van het menu: Explorer Geeft je een overzicht van je bestanden en de structuur waarin ze opgeslagen zijn Source control Als je veranderingen aangebracht hebt, moeten die opgeslagen worden. Dit doe je steeds met ‘Commit changes’ en elke keer als je dat doet voeg je een Message toe, gevolgd door Ctrl-Enter. Als veranderingen niet opgeslagen zijn, verschijnt er een getalletje, dat het aantal bestanden wat veranderd is, aangeeft. Dit getalletje verdwijnt zodra je code opgeslagen is. Als je de webeditor wilt verlaten, zonder dat je de veranderingen opgeslagen hebt, krijg je een melding. Code toevoegen Tik onderstaande code in in index.html, in de editor rechts Je ziet een 1-tje verschijnen bij de Source control We bekijken de code: Begin- en eindtag van de html-elementen De head voor de meta-data met daarin de titel, die later op het tabblad komt De body voor de inhoud van de pagina Sla de veranderingen op mbv. ‘Commit changes’: Dus een Message intikken, gevolgd door Ctrl-Enter en het 1-tje verdwijnt. Bekijk je 1e pagina Open een nieuw tabblad en tik in: .github.io en je 1e pagina moet te zien zijn. Dit kan soms wel even duren, wees geduldig…..!! Als je het voorbeeld overgetikt hebt, heb je wat tekst en een titel in het tabblad. 2e pagina: File (Bestand) en links toevoegen Hoe maak je een 2e pagina Hoe link de 2e pagina aan je Homepage Makkelijke manier: Klik op het meest linkse icoontje, dan wordt er een bestand (file) aangemaakt en geeft het nieuwe bestand een goede naam. Andere manier: Klik linksboven in het menu op de 3 streepjes en klik via File → New File aan. Dit wordt een volgend .html-bestand. NIET File → New Text File Als je dit per ongeluk hebt gedaan, haal dat dan weg door op het kruisje te klikken Tik in bij Select File Type: html, gevolgd door Enter Tik nu de naam van het nieuwe bestand in, in dit volgende venster: Er moet komen: binairstelsel.html, en klik op ok. Links in je menu zie je dat het nieuwe bestand is toegevoegd Kopieer de code van index.html naar binairstelsel.html en verander de titel en de tekst enigszins.
